# 📌 Petunjuk Set-Up Environment

## 🖥️ A. Set-Up Environment di folder frontend

Silahkan ikuti langkah-langkah berikut:

1. Buka terminal
2. Ketik **"cd frontend"** untuk menjalankan perintah hanya di folder frontend
3. Ketik **"npm install"** agar perintah npm yang diperlukan dapat berjalan
4. Ketik **"npm run dev"** untuk menjalankan bagian front-end🚀

---

## ⚙️ B. Set-Up Environment di folder backend

Silahkan ikuti langkah-langkah berikut:

1. Buka terminal
2. Ketik **"cd backend"** untuk menjalankan perintah hanya di folder backend
3. Ketik **"npm install"** agar perintah npm yang diperlukan dapat berjalan
4. Ketik **"cd src"** agar berkas yang dijalankan itu yang ada di folder src
5. Ketik **"node server.js"** untuk menjalankan bagian back-end🔧

---

## ⚠️ Catatan Penting

* Pastikan sudah memiliki dan menginstall **Node.js** di perangkat kamu 💻
